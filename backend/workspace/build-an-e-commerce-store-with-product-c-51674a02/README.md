## Tech Stack
- Frontend: React, TypeScript-style, Tailwind CSS
- Backend: Node.js, Express, MongoDB (Mongoose)
- Auth: JWT

## Getting Started

```bash
# Backend
cd backend
npm install
cp .env.example .env
npm run dev

# Frontend (in a new terminal)
cd frontend
npm install
npm run dev
```

Or with Docker:
```bash
docker-compose up --build
```
