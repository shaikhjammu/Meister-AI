# School & Student Portal System

> Generated automatically from the prompt: "i want student record app for college attendance"

## Roles
- Admin
- Teacher
- Student
- Parent

## Features
- Student, Teacher, and Parent Portals
- Daily Student Attendance & Leave Tracker
- Exam Results & GPA Report Card Generator
- Interactive Class Timetable & Schedule
- Fee Payment & Outstanding Dues Overview
- School Announcement & Notice Board

## Tech Stack
- Frontend: React, TypeScript-style, Tailwind CSS
- Backend: Node.js, Express, MongoDB (Mongoose)
- Auth: JWT

## Getting Started

```bash
# Backend
cd backend
npm install
cp .env.example .env
npm run dev

# Frontend (in a new terminal)
cd frontend
npm install
npm run dev
```

Or with Docker:
```bash
docker-compose up --build
```

## Testing
```bash
cd backend
npm test
```
